# Contributing to Quran Audio Project

Thank you for your interest in contributing to this project!

## How to Contribute

1. **Fork the repository** - Create your own fork of this repository
2. **Create a branch** - Create a new branch for your changes
3. **Make your changes** - Make your changes in your branch
4. **Test your changes** - Ensure your changes work as expected
5. **Submit a Pull Request** - Submit a PR to the main branch

## Pull Request Process

- All contributions must be submitted via Pull Request
- PRs must be reviewed and approved by the repository owner (@rickseven)
- Do not push directly to the main branch
- Include a clear description of your changes

## Code Review

All pull requests will be reviewed by:
- **@rickseven** (maseric7@gmail.com)

Please be patient while waiting for review. We will do our best to review PRs in a timely manner.

## Questions?

If you have questions, please open an issue or contact the repository owner.
